# Contributing

Thanks for your interest in improving the Codex Bridge.

## Getting Started

1. Fork and clone the repo.
2. Run it locally (see `README.md`).
3. Make your changes in a focused branch.
4. Open a PR with a clear description and screenshots/logs when relevant.

## Code Style

- Keep changes minimal and well-scoped.
- Prefer small, composable helpers over inline duplication.
- Add comments only when behavior is non-obvious.

## Reporting Issues

Please include:

- OS and Node.js version
- Exact command you ran
- Relevant logs (redact secrets)
- Steps to reproduce
