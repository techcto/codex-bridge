# Roadmap

## Near Term

- Improve latency by reducing per-request startup overhead.
- Add provider-agnostic auth helpers and clearer error reporting.
- Expand OpenAI-compatible proxy coverage for new endpoints.

## Mid Term

- Add a long-lived runtime worker mode for lower latency.
- Ship CMS adapter templates for popular platforms.
- Provide a secure remote execution mode for heavier jobs.

## Long Term

- Offer a stable plugin interface for CMS-specific actions.
- Add observability hooks for tracing and metrics.
